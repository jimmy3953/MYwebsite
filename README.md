
# Horizon International School — OUM Introduction to Web Programming — Task 1

## Pages
1. index.html — Home
2. about.html — About the School
3. teachers.html — About the Teachers
4. activities.html — Co-curricular Activities
5. facilities.html — Facilities & Student Support
6. news.html — News, Events & Achievements
7. contact.html — Contact / Parent Enquiry

## Supporting files
- css/style.css — consistent responsive styling
- js/script.js — mobile menu, active navigation, scroll reveal, slideshow, activity filtering and form validation

## Requirement coverage
- One Home Page + six additional pages
- Clear navigation linking all pages
- School background, vision, mission, objectives, location, operating hours and leadership
- Teacher names, profile images, subjects, qualifications, experience, roles and profiles
- Clubs, societies, sports, uniformed bodies, competitions and participation opportunities
- Classrooms, computer lab, library, science lab, sports facilities, canteen, counselling and health/safety support
- News, events, dates, achievements, awards and structured event table
- Contact details and parent enquiry form
- Semantic HTML5 structure with headings, sections, lists, links, images, tables and form controls
- Consistent CSS and responsive layout for desktop/tablet/mobile
- Descriptive alt text for images and accessible form labels
- Multimedia images and interactive JavaScript features
- Parent-friendly and professional visual identity

## Important note for submission
The site uses external image URLs from Unsplash so the prototype has realistic photographs without bundling copyrighted image files into the project. For a fully offline submission, download/replace those images with appropriately licensed local images and update the src URLs.

The school, staff names, statistics and calendar entries are fictional website content created for the assignment prototype.

The Contact page front-end form is prepared for Task 2 server-side integration. Its JavaScript currently validates the fields and displays a confirmation message without sending data to a server.

## Source Code Organisation
The source code is organised with clear section comments to make the project easy to read, maintain and assess.
- HTML pages: document-level comments identify the purpose of each page and major page sections.
- `css/style.css`: grouped comments identify global styles, layout, components, forms, accessibility and responsive rules.
- `js/script.js`: grouped comments identify navigation, animations, slideshows, activity filtering and Task 2 form validation.
